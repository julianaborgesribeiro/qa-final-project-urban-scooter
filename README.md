Projeto - Urban Scooter - Testes Web e API

1. Sobre o projeto: Projeto desenvolvido durante a formação em QA pela TripleTen, com foco na validação da interface web e do backend do aplicativo Urban Scooter.

2. Objetivo: Projetar e executar casos de teste positivos e negativos para verificar o funcionamento dos campos do formulário de pedido e das funcionalidades de adição e exclusão de entregadores pela API.

3. Atividades realizadas

A) Testes da aplicação Web

- Análise dos requisitos e elaboração de casos de teste;
- Validação dos campos do formulário "About Customer";
- Aplicação de classes de equivalência e valores-limite;
- Execução dos testes no Google Chrome e Opera;
- Identificação e documentação de bugs no Jira.

B) Testes de Backend e API

- Análise dos requisitos e da documentação da API;
- Elaboração de casos de teste para adicionar e excluir entregadores;
- Execução de requisições e validação das respostas HTTP;
- Testes positivos e negativos;
- Registro dos resultados e documentação de bugs no Jira.

4. Resultados

A) Aplicação Web

- 40 casos de teste
- Chrome: 36 aprovados e 4 reprovados;
- Opera: 36 aprovados e 4 reprovados;
- 4 bugs registrados no Jira.

B) Backend e API

- 22 casos de teste;
- 12 aprovados e 10 reprovados;
- 10 bugs registrados no Jira.

5. Ferramentas e tecnologias

- Google Chrome;
- Opera;
- Postman;
- Jira;
- Google Sheets;
- API REST;
- HTTP.

6. Aprendizados: Experiência prática em análise de requisitos, design e execução de testes funcionais, testes positivos e negativos, classes de equivalência, valores-limite, testes de API, validação de respostas HTTP e documentação de defeitos.
